# Strike School (published site)

Interactive lessons for learning the stock market and options trading.

**Open the app: https://acsgunx.github.io/strike-school-site/**

This repository only holds the published files. It is redeployed automatically from the source repository whenever a change is merged there, and each deploy replaces everything here, so edits made directly in this repository will be lost.

For learning only. Every company, fund and price in the app is made up or simulated. Nothing here is financial advice.
